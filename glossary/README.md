# English-Uzbek glossary of AI and NLP terms

`glossary_en_uz.csv` is the single source of truth for terminology in the textbook and notebooks.

| Column | Meaning |
|---|---|
| `term_en` | English term |
| `term_uz` | Uzbek term (Latin script, canonical apostrophes) |
| `definition_uz` | Short definition in Uzbek |
| `chapter` | Chapter where the term is introduced (1-14) |
| `status` | `proposed` → `reviewed` → `approved` (approved by a linguist reviewer) |

The seed list has 22 terms; the target for the printed book is 400+.
Propose new terms or corrections with the *Glossary term* issue template.
